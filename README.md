# Customer Segmentation using K-Means Clustering

A Streamlit application for performing K‑Means clustering on customer data. Users can upload a CSV file, select any two numerical features, and explore clusters via the Elbow Method, scatter plots, and cluster size distributions.

Features

Interactive File Upload: Load your own CSV dataset.

Dynamic Feature Selection: Choose any two numerical columns for clustering.

Elbow Method Visualization: Identify the optimal number of clusters.

Cluster Scatter Plot: Visualize customer segments and centroids.

Cluster Size Distribution: Bar chart showing the number of samples per cluster.

Modular Codebase: Well‑structured modules for utilities, clustering logic, and the Streamlit app.
